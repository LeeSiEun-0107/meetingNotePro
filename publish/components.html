컴포넌트 규격

`theme.js` 의 `window.UI` 에 클래스로 고정. 화면마다 다시 정하지 않고 이름만 가져다 씀

01

팔레트

dot 은 띠와 점, text 는 흰 배경 위 글자

카드 배경은 언제나 무채색. 색은 좌측 6px 띠와 라벨에만 씀. 면적으로 쓰지 않음

02

버튼

높이 44px 고정 (h-11)

window.UI.btnPrimary  /  window.UI.btnGhost  /  window.UI.btnDanger
03

입력

기본 · 포커스 · 오류 세 상태

가입에 쓴 주소

없는 초대코드

04

배지

할 일 상태 3종 + 권한 2종

05

알림

`window.notice(kind, title, body)`

07

지킬 것

  • - 색은 좌측 6px 띠와 라벨에만. 카드 배경을 물들이지 않음
  • - 버튼 높이는 44px 하나. 화면마다 다른 크기를 만들지 않음
  • - 모서리는 카드 `rounded-xl`, 패널 `rounded-2xl` 두 가지만
  • - 새 색을 추가하려면 `theme.js` 팔레트에 먼저 등록
  • - `!important` 금지 (05-conventions 금지 5개 중 하나)
